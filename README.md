This entry hands in a single-line resignation letter: a polite opener, a clean break, and a punchline about walking out with the one thing the office cannot keep. The program reads that line from `entry.txt`, checks it is exactly one line of 1 to 140 characters with no stray whitespace at either end, and copies it unchanged to the output folder.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```
